# Example

A Product built on the Skeleton (`packages/skeleton/`). This file is generated by `pnpm new-product`; the repo's root `AGENTS.md` has the rules.

- Identity, texts and sender: `product.config.ts`. Theme: `src/client/styles.css`.
- Features: `src/features/<id>/`, listed in `src/features/index.ts`.
- Commands: `pnpm dev example`, `pnpm --filter example run typecheck|lint|test|e2e`, `pnpm factory:verify`.
- Never edit `packages/skeleton/`; if the Skeleton lacks something, grow its interface in a separate change.
