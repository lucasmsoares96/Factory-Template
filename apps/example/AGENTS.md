# Example

A Product built on the Skeleton (`packages/skeleton/`). This file is generated by `pnpm new-product`. The root `AGENTS.md` has the repo rules; read `packages/skeleton/AGENTS.md` for how the platform works.

## Layout

- `product.config.ts`: identity (`id`, `title`, `emailFrom`, `domain`) and texts per locale. It reaches the browser: data only, no server code.
- `src/client/styles.css`: theme (shadcn tokens). `src/worker.ts`: the Worker, a `createApp` call.
- `src/features/<feature>/`: product behaviour, listed in `src/features/index.ts`.
- `drizzle/`: this Product's migrations (they run after the Skeleton's).
- `test/`: Worker tests; `playwright.config.ts` runs the Skeleton's E2E specs plus this Product's.
- `src/mcp-tools.gen.json`: snapshot of the MCP tools, written by `pnpm generate`.

## Commands

- `pnpm dev example`
- `pnpm --filter example run typecheck|lint|test|e2e`
- `pnpm generate`, then commit what changed.
- `pnpm factory:verify` before you finish.

## Rules

- Never edit `packages/skeleton/`. If the Skeleton lacks something, grow its interface in a separate change.
- A feature is a `Feature` (`id`, `api(app)`, optional `mcp`, `seed`) in `src/features/<id>/`, with `schema.ts`, `routes/` (signed in), `public/` (visitors) and `messages.ts` (spread into `product.config.ts`).
- API routes need `operationId`, `summary`, `description`, every response with stable error codes, and `limit` (default 50) plus a cursor on lists. Each operation becomes an MCP tool unless it sets `x-mcp: false`; the tool snapshot changes in the same commit.
- The database only adds. Generate a migration with `pnpm --filter example run db:generate`; never edit a published one.
- UI texts go through the messages (`en` and `pt-BR`), never as literals in components.
- Tests: Worker tests over HTTP, browser tests with the generated MSW handlers, Playwright E2E. Locate elements by role plus the i18n key or `data-testid`, never by literal text. Tag screenshots `@evidence`.
- Recipes: skills `skeleton-add-feature`, `skeleton-add-endpoint`, `skeleton-add-migration`, `skeleton-evidence-test`.
